🧠 Как учить меню

Принцип якоря

Для каждого блюда найди одну якорную деталь. Рибай = «глаз» (rib + eye). Тендерлойн = «мышца не работает = нет жира = Rare/MR». Казеречче = «casa = дом — домашняя паста из Сицилии».

Не учи список ингредиентов. Учи историю + одну ключевую особенность.
Метод «Что скажу гостю?»

После прочтения сразу проговори вслух: «Гость спрашивает — в чём разница между форелью и лососем? Я отвечу...» Мозг запоминает то, что говоришь, а не то, что читаешь.

После каждой секции закрой шпаргалку и объясни блюдо вслух воображаемому гостю.
Группировка по соусам

Сливочные: Порчини, Альфредо, Цыплёнок. Томатные: Болоньезе, Аррабиата, Дьявола, Маргарита. Демиглас: Тендерлойн, Рибай, Тальятеле с рагу, Щёчки. Знаешь соус — знаешь разницу.

Нарисуй 4 кружка: Томат / Сливки / Демиглас / Масло-Лимон — впиши блюда.
Аллергены — правило «ГЛЯРС»

Самые частые: Глютен, Лактоза, Яйцо, Рыба, Соя. Для каждого блюда: «Есть ли кто из ГЛЯРС?» Цезарь — вся пятёрка + горчица + рак.

Цезарь — чемпион по аллергенам. Анчоусы в заправке = аллерген Рыба, даже без добавок.
Вина — три правила

Красное мясо = красное вино. Рыба/морепродукты = белое. Острые блюда = Riesling (кислота гасит остроту). Chardonnay = сливочные блюда. Три правила покрывают 80% вопросов.

Якоря: Hans Greyl SB = универсальный белый. Querciabella Rosso = к стейкам. Riesling = к острому.
Время — запомни исключения

Большинство блюд 15–20 мин. Исключения: Цыплёнок 30–35 мин — предупреждать сразу. Стейки 25–35 мин. Супы и десерты 5–15 мин. Крем-брюле 5 мин.

Гость заказал Цыплёнка — скажи немедленно: «Цыплёнок готовится 30–35 минут».

📖 Основы: как понимать алкоголь

Как делают любой алкоголь — 3 шага

1. Ферментация — дрожжи превращают сахар в спирт (вино, пиво, саке). Максимум ~15% алкоголя.
2. Дистилляция — нагревают и собирают пары спирта → крепкий алкоголь (виски, водка, коньяк, джин). Можно получить 40–96%.
3. Выдержка — хранение в бочках или ёмкостях. Добавляет цвет, вкус, сложность.

Вино и пиво = ферментация. Виски/коньяк/ром = ферментация + дистилляция + выдержка. Водка = дистилляция без выдержки.
Как говорить с гостем о напитке

Структура любого описания: Откуда + Из чего + Вкус + К чему подходит.
Пример: «Это шотландский виски из региона Speyside, сделан из ячменя, с нотами фруктов и мёда, выдержан в бочках из-под хереса. Хорошо подойдёт тем, кто любит мягкий, некурительный виски».
Запомни: гостя интересует ощущение, а не технология.

Не говори «10 лет выдержки» без объяснения. Говори: «10 лет выдержки = более глубокий, мягкий, сложный вкус».

🏺 Крепленые вина

Что такое крепленое вино?

Вино, в которое добавили виноградный спирт во время или после ферментации. Это останавливает брожение (сохраняет сладость) и повышает крепость до 15–22%. Порт (Португалия) — добавляют спирт во время брожения → сладкое. Херес/Sherry (Испания) — добавляют после → от сухого до сладкого.

Крепленое = вино + виноградный спирт = дольше хранится + выше крепость + разные стили от сухого до очень сладкого.

🥃 Scotch Single Malt Whisky

Что такое Single Malt Scotch?

Виски = зерновой дистиллят, выдержанный в дубовых бочках. Single Malt = из соложенного ячменя (только ячмень!) + одна дистиллерия + Шотландия + выдержка минимум 3 года + не менее 40%. «Single» = одна дистиллерия. «Malt» = соложенный ячмень.
Blended = смесь нескольких дистиллерий (Chivas, Johnnie Walker). Более мягкий и доступный.
Бочки важны: херес (sherry) = сухофрукты, орехи, шоколад. Бурбон = ваниль, карамель. Торф = дым, йод.

5 регионов = 5 разных характеров: Speyside = фрукты+мёд. Highland = разнообразие. Lowland = лёгкий. Islay = дым+торф. Islands = морской+умеренный торф.

✨ Коньяк, Арманьяк, Бренди

Коньяк — что это?

Коньяк = французский бренди из региона Cognac. Делается из белого винограда (Ugni Blanc) → двойная дистилляция в медных кубах → выдержка в дубовых бочках (лимузенский дуб).
Система обозначений:

XO (Extra Old) = мин. 10 лет. Богатый, сложный. Пить чистым.

🌿 Джин

Джин — что это?

Джин = зерновой дистиллят, ароматизированный можжевельником (juniper) и другими ботаниками (цитрус, кориандр, специи, цветы и т.д.). Вкус зависит от набора ботаников.
Стили:

Genever = голландский прародитель джина, более солодовый и тяжёлый.
Базовое правило: хороший джин = хороший тоник + правильный лёд + правильный гарнир.

🌵 Текила и Мескаль

Текила — что это?

Текила = мексиканский дистиллят из голубой агавы (Blue Agave Tequilana Weber), только из региона Халиско и ещё 4 штатов.
Категории по выдержке:
Blanco/Silver = без выдержки. Чистый, агавовый вкус. Для коктейлей.
Reposado = выдержка 2–12 мес в дубе. Мягче, ваниль, дерево.
Añejo = 1–3 года. Сложный, карамель, специи. Пить чистым.
Extra Añejo = 3+ года. Как коньяк. Для сиппинга.
Мескаль vs Текила: Мескаль = из ЛЮБОГО вида агавы, чаще с дымным вкусом (пьеча). Текила = только из голубой агавы. Мескаль = более традиционный и сложный.

Blanco = коктейли. Reposado = переходный. Añejo = сиппинг. Don Julio 1942 = культовый. Clase Azul = самый дорогой в карте.

🍬 Ром

Ром — что это?

❄️ Водка

Водка — что это?

Водка = нейтральный зерновой (или картофельный) дистиллят, очищенный фильтрацией, разбавленный водой до ~40%. Максимальная чистота — минимум посторонних вкусов. Разница брендов в мягкости, «водяном» ощущении, лёгкости.
Делают из: пшеница, рожь, ячмень, картофель (Belvedere = рожь; Grey Goose = пшеница; Beluga = пшеница/рожь).

Водка = чистота + мягкость. Тёплая водка = не ошибка — раскрывает вкус. Холодная = максимальная чистота ощущений.

🍶 Саке и Байцзю

Саке — японский рисовый напиток

Что такое саке?

Саке = ферментированный напиток из шлифованного риса. Не вино, не пиво, не дистиллят — уникальная категория. Крепость 14–16%. Ключевой фактор = степень шлифовки риса (seimai-buai): чем больше сошлифовано → тем чище и деликатнее вкус.
Junmai = только рис, вода, кодзи, дрожжи. «Чистое» саке.
Ginjo/Daiginjo = высокая шлифовка (≥40/50% удалено). Фруктовый, цветочный, элегантный.
Genshu = неразбавленное. Более концентрированное.

Чем длиннее название (Junmai Daiginjo) — тем дороже и тоньше. Подавать охлаждённым (Ginjo/Daiginjo) или тёплым (обычное). Бокал для белого вина или традиционная чаша.

Байцзю — китайский крепкий дистиллят

Что такое байцзю?

Байцзю = крепкий зерновой дистиллят из Китая. Самый потребляемый крепкий алкоголь в мире. Крепость 38–53%. Делают из сорго (чаще) с уникальной закваской цюй (смесь плесени, дрожжей, бактерий) → твёрдая ферментация → дистилляция твёрдой массы → выдержка в керамике.
Стили:
Strong Aroma = яркий фруктовый, сладковатый, насыщенный.
Sauce Aroma = сложный, ферментированные ноты, соевые оттенки, длинное послевкусие.
Light Aroma = чистый, мягкий, лёгкий.
Это не водка, не саке. Уникальная категория. В культуре — напиток для тостов в компании.

Strong Aroma = для первого знакомства. Sauce Aroma = для знающих гостей. Подаётся в маленьких рюмках в графинчике даже при заказе 50 мл.

🫒 Аперитивы, Вермуты, Биттеры

Что такое аперитив?

Аперитив = напиток перед едой, стимулирующий аппетит. Вермут = вино, настоянное на полыни и ботаниках. Биттер = крепкий, горький настой трав. Ликёр = сладкий настой. Амаро = горький итальянский ликёр после ужина.

Lillet Blanc = к рыбе + как аперитив. Campari = Negroni + Spritz. Contratto / Antica Formula = для классических коктейлей. Amaro = после ужина.
